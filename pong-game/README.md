# 🏓 Pong Game

A classic Pong game built with vanilla HTML, CSS, and JavaScript. Play against an AI opponent with smooth physics and collision detection.

## 🎮 Features

✅ **Player Controls**
- Mouse movement for left paddle
- Arrow keys (↑↓) for alternative control

✅ **Computer AI**
- Intelligent opponent paddle
- Adjustable difficulty

✅ **Game Physics**
- Smooth ball movement and bouncing
- Wall collision detection
- Paddle collision with spin effects
- Ball acceleration on paddle hits

✅ **Visual Design**
- Modern gradient background
- Neon-style glowing effects
- Real-time scoreboard
- Center line divider

✅ **Gameplay**
- Score tracking
- Start/Pause with SPACE key
- No external dependencies

## 🚀 How to Play

1. Open `index.html` in your web browser
2. Press **SPACE** to start the game
3. Use your **mouse** or **Arrow Keys** to move the left paddle
4. Bounce the ball past the computer's paddle to score
5. First to reach the winning score wins!

## 🏀 Game Rules

- Move your paddle (left side) to hit the ball
- Don't let the ball pass your paddle
- Each point scored when ball goes past opponent's paddle
- Ball bounces off top and bottom walls
- Ball gains spin based on where it hits the paddle

## 📁 Files

- `index.html` - Game structure and canvas
- `style.css` - Styling and visual effects
- `script.js` - Game logic and physics

## 🎨 Customization

You can easily customize:
- Ball speed: Modify `ball.speed`
- Paddle speed: Adjust `leftPaddle.speed` and `rightPaddle.speed`
- Canvas size: Change `canvas.width` and `canvas.height`
- Colors: Edit color values in `style.css`

## 💻 Browser Support

Works on all modern browsers that support:
- HTML5 Canvas
- ES6 JavaScript
- CSS3 (Backdrop filter, gradients)
